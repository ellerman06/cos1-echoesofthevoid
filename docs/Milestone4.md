Milestone 4
Features Completed
I focused on polishing and completing Echoes of the Void. The game now includes planet travel, random events, trading, ship repairs, save/load functionality, and win/lose conditions. I also added additional planets, rare events, and a captain naming system.

Refactoring and Improvements
I improved input validation using getline(), stoi(), and try/catch, updated the save/load system to properly restore the current planet, and improved overall code organization between classes.

Bugs Resolved
I fixed menu navigation issues, save/load inconsistencies, invalid input handling, and fuel purchasing edge cases that allowed players to buy more fuel than their ship could store.

Usability Improvements
I added an objectives screen, resource warning messages, additional random events, and more planet destinations. I also updated the menus to provide clearer information and make the game easier to play.
